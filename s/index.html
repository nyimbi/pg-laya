Local, plain-language predicates for PostgreSQL
v0.3.0 · runs locally by default · no embeddings, no index

Ask your Postgres tables
questions in plain language.

laya(table, 'the customer is angry') is an ordinary boolean SQL predicate. Every row is judged by Laya — a local, non-autoregressive System-1 model that returns calibrated probabilities instead of generated text. Write the condition the way you would say it, and let Postgres do the rest.

Get started → Browse 25+ examples
quick start
CREATE EXTENSION laya CASCADE;

-- filter rows with a plain-language condition
SELECT * FROM people WHERE laya(people, 'the name is European');

-- rank rows and take the top ones
SELECT subject, laya_prob(tickets, 'the customer is angry') AS p
FROM tickets ORDER BY p DESC LIMIT 20;

-- classify rows into a closed set
SELECT laya_choice(tickets, 'which team should handle this?',
                   ARRAY['billing', 'technical', 'security', 'sales']) AS team,
       count(*)
FROM tickets GROUP BY 1;

laya() is a STABLE function, so it composes with everything else in SQL: AND age > 40, joins, GROUP BY, LIMIT, ORDER BY laya_prob(…), views and materialised pipelines.

How it works, in three steps

The row becomes the question

The whole row is serialised with to_json and sent to the model along with your condition. Column names are part of what the model sees, so descriptive names help.

Laya returns a calibrated number

Instead of generating text, Laya does one forward pass and returns a probability (or a probability vector for a closed set). No index, no vector column, no embeddings to keep in sync.

Postgres treats it as a boolean

laya() is just a WHERE predicate. Cheaper filters run first, answers are cached per row for the session, and the result streams back like any other query.

What you get

Plain-language WHERE

Filter rows with a sentence. Add a threshold argument or laya.threshold for a stricter cut.

Rank & score

laya_prob for a 0..1 score to ORDER BY; laya_score for a rubric position.

Classify & route

laya_choice picks one label from a closed set; laya_confidence tells you when to route to a human.

Local by default

Ships with Ollaya, a single-binary model server, installed as a system service next to Postgres. No cloud key, data stays on the machine.

Fast to first answer

Read-ahead streams rows in physical order, batches 20 per request, and answers each row as soon as its batch returns.

Composable SQL

Works in WHERE, SELECT, joins, GROUP BY, CASE and views.
